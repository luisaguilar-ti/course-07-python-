# Guía de estilo PEP 8 y legibilidad del código

## Introducción

Python es conocido por ser un lenguaje fácil de leer. Para mantener esa característica, la comunidad creó una guía oficial de estilo llamada **PEP 8 (Python Enhancement Proposal 8)**.

PEP 8 reúne recomendaciones para escribir código limpio, consistente y fácil de mantener.

Aunque sus reglas no son obligatorias, seguirlas facilita que otros programadores comprendan y colaboren en un proyecto.

---

# ¿Qué es una guía de estilo?

Una guía de estilo es un conjunto de recomendaciones sobre cómo escribir y organizar el código.

Su objetivo es:

- Mantener un formato uniforme.
- Mejorar la legibilidad.
- Facilitar el mantenimiento del código.
- Favorecer el trabajo en equipo.

---

# ¿Qué es PEP 8?

PEP significa **Python Enhancement Proposal**.

La propuesta número 8 (**PEP 8**) define las convenciones de estilo recomendadas para escribir código en Python.

La idea principal de PEP 8 es:

> **"El código se lee mucho más de lo que se escribe."**

Por ello, el código debe ser claro y fácil de entender.

---

# ¿Por qué seguir PEP 8?

Aplicar las recomendaciones de PEP 8 ofrece varias ventajas:

- Hace que el código sea más fácil de leer.
- Facilita el mantenimiento.
- Reduce errores.
- Permite que diferentes programadores utilicen un mismo estilo.
- Mejora la colaboración en proyectos grandes.
