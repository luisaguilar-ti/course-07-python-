## Objetivos del módulo

Al finalizar este módulo serás capaz de:

- Crear funciones reutilizables.
- Definir parámetros y utilizar argumentos.
- Devolver valores mediante `return`.
- Comprender la diferencia entre variables globales y locales.
- Utilizar funciones integradas de Python.
- Importar módulos de la Biblioteca estándar y bibliotecas externas.
- Escribir código siguiendo la guía PEP 8.
- Mejorar la legibilidad y el mantenimiento del código.
