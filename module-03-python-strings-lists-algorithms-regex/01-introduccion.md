# Introducción

## Objetivo

Los analistas de seguridad trabajan con grandes cantidades de datos. Este módulo amplía los conocimientos de Python vistos anteriormente, incluyendo tipos de datos, variables, condicionales, bucles y funciones.

## Temas del módulo

- Cadenas.
- Listas.
- Extracción de caracteres y elementos.
- Algoritmos.
- Expresiones regulares.
- Búsqueda de patrones en cadenas y registros.

El objetivo es utilizar estos conceptos para escribir código Python aplicable a tareas de seguridad.
